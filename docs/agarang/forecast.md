# 예보 엔진 (#4)

구현: `shared/forecast/ForecastEngine.kt`, `ForecastPolicy.kt`, `AgeReferenceModel.kt`.
Android·Pleos SDK·네트워크에 의존하지 않는 Kotlin 판단 코드다. #3의 확인된 `CareRecord`를 받아 F2·F4·F5가 같은 결과를 소비하도록 한다. 화면 연결은 #7·#8에서, 실제 ETA 공급자는 #5에서 구현한다.

## 입력과 결과

`evaluate(ForecastInput)`은 입력의 평가 시각만 사용한다. 같은 입력·정책에는 같은 결과를 반환하고 기록을 수정하지 않는다. `evaluate(care, journey, driveSession)` 편의 함수만 생성자에 주입한 시계를 읽는다.

- 입력: 월령·보호자 설정·돌봄 기록, UTC epoch 밀리초 평가 시각, 출처·관측 시각·상태가 붙은 여정, 선택적인 보호자 확인 착석 세션.
- 결과: 전체 계획 단계, 필요별 단계·근거·간격 범위·예상 시간 범위, 행동 후보, 도착과 돌봄의 관계, 정보 부족 여부와 데모 표시.
- `CareTimeEstimate.expectedAtEpochMillis`는 설정 시각 또는 이력의 중앙값이다. `earliestAtEpochMillis`·`latestAtEpochMillis`를 함께 제공한다. 이력 범위는 관측 최솟값·최댓값이지 통계적 신뢰구간이 아니다.
- `anchorAtEpochMillis`는 실제 기록 또는 보호자 확인 세션의 시작이다. 기록이 없으면 평가 시각을 가짜 마지막 수유·기상 시각으로 넣지 않는다. `historyIntervalCount`는 사용한 간격의 수다.
- `NeedForecast.reference`는 일반 자료의 적용 범위와 출처 ID를 별도로 전달한다. 보호자 설정·개인 이력·일반 참고·데모·정보 부족을 구분한다. `usesGeneralTiming`은 일반 여행 간격으로 절대 시간 범위를 계산했는지 표시하며, 데모 표시가 있어도 이 한계를 유지한다.
- `isLimited`가 true이면 일부 필요나 여정을 평가하지 못했거나 일반 여행 참고값을 사용한 결과다. 전체 단계는 계산 가능한 필요에 대한 계획 단계이며, 아기의 전체 상태나 안전을 보증하지 않는다. UI는 전체 단계만 떼어 표시하지 않고 정보 부족과 필요별 근거를 함께 표시해야 한다.

## 개인 예보와 첫날 모델

| 필요 | 개인 계산 | 설정·기록 부족 시 |
| --- | --- | --- |
| 수유 | 보호자 수유 간격 우선. 없으면 최근 수유 간격 최소 3개로 중앙값·관측 범위를 계산하고 마지막 수유에 더한다 | 월령별 일반 참고 범위만 제공. 일반 수유 간격을 개인의 다음 수유 시각으로 변환하지 않음 |
| 수면 | 보호자 깨어 있는 시간 우선. 없으면 기상→다음 수면 시작 간격 최소 3개로 계산 | 검토한 공식 자료에서 개인 예보에 적용할 월령별 분 단위 기본값을 확보하지 못해 UNKNOWN. 마지막 기록이 수면 시작이면 기록상 수면 중으로만 표시하고 기상 시각은 예측하지 않음 |
| 착석 휴식 | 종료되지 않은 보호자 확인 세션과 보호자 휴식 간격 사용 | 0~11개월은 일반 여행 참고 간격 120~180분의 계획 범위 사용. 세션이 없으면 절대 시각은 없음. 12~24개월에는 수치를 확장 적용하지 않음 |
| 기저귀 | 이 단계에서 시간 예보하지 않음 | 기록과 직접 확인 경로 유지. 근거 없는 고정 교체 주기를 만들지 않음 |

첫날에는 월령으로 아래 참고 모델을 선택한다. 기록이 0건이면 수유·수면 예상 시각은 비워 두고 출발 전 확인을 제안한다. 착석 세션이 확인됐다면 기록 0건이어도 제한된 휴식 계획을 계산할 수 있다.

| 월령 | 수유 참고 | 가정·한계 |
| --- | --- | --- |
| 0개월 | 60~240분의 넓은 맥락 범위 | 완료 월령만으로 첫 며칠과 이후 몇 주를 구분할 수 없어 CDC의 두 시기·수유 방식 설명을 넓게 묶은 제품 가정. 이 범위를 개인 일정이나 안전한 대기 시간으로 쓰지 않음 |
| 1~5개월 | 120~240분의 일반 맥락 범위 | CDC의 초기 몇 주·몇 달 안내를 6개월 전의 맥락으로 매핑한 제품 가정. 수유 방식·클러스터 수유·시간대·개인차를 확정할 수 없어 개인 시각으로 환산하지 않음 |
| 6~11개월 | 고형식과 반응에 따른 수유, 수치 없음 | 하루 횟수를 24시간으로 나눠 간격을 만들지 않음 |
| 12~24개월 | 개인 생활 리듬 확인, 수치 없음 | 일반적인 개인 간격을 정할 근거가 없어 보호자 설정·이력을 기다림 |

카시트 참고 범위는 AAP의 낮 시간 여행 휴식 안내에서 가져왔다. 현재 입력에는 시간대·조산 여부·개별 건강 상태가 없으므로 밤의 더 긴 범위를 자동 선택하지 않는다. 0~11개월 적용과 낮 범위를 기본 여행 계획에 사용하는 것은 제품 범위 가정이다. 이 수치는 카시트의 의학적 허용 시간·안전 상한·수면 권장 시간이 아니다. `CHECK_SLEEP_AT_ARRIVAL`도 기록상 수면과 도착이 겹쳤을 때 확인하라는 후보이며, 카시트에서 계속 재우라는 지시가 아니다.

## 계산 정책 v1

소아과 기준이 아닌 제품 계산 규칙은 `ForecastPolicy`로 분리했다. 값을 변경하면 호출자가 정책 버전도 바꾼다.

| 정책 | 기본값·동작 |
| --- | --- |
| 시간 단계 | 가장 이른 계획 시각까지 15분 이하(이미 지난 경우 포함)는 IMMINENT, 60분 이하는 CAUTION, 그 밖은 RELAXED. 예상 시각이 없으면 UNKNOWN |
| 여정 단계 | 돌봄 범위의 시작이 도착보다 빠르면 전체 계획 단계를 최소 CAUTION으로 하고 정차 계획 후보를 제공. 정확히 같으면 도착 시 확인으로 구분 |
| 이력 | 최근 14일, 가장 최근 최대 6개 간격. 최소 3개가 필요. 1분 미만 간격은 빠른 중복 입력의 영향을 줄이기 위해 학습에서 제외 |
| 오래된 기준점 | 마지막 돌봄·세션 시작이 24시간보다 오래됐으면 UNKNOWN. 계속 임박 상태로 유지하지 않음 |
| 여정 최신성 | NAVI_SDK·DEMO의 READY만 사용. 관측 후 5분까지 유효. STALE, 미래 관측, 지난 ETA, ETA 없음, 권한 거부·실패 등은 여정 비교에서 제외 |
| 도착 임박 | 15분 이내 도착하고 기록상 수면 중이며 도착 전 돌봄 후보가 없으면 도착 시 수면 확인 후보 제공 |

단계는 가장 이른 범위로 계산한다. 예를 들어 개인 이력 범위가 150~180분이고 도착이 165분 뒤라면 중앙값 180분만 보고 도착 전에 돌봄이 없다고 판단하지 않는다.

`CARE_THEN_DEPART`, `PLAN_STOP` 등은 실행 명령이 아닌 행동 후보다. 보호자 확인 세션은 차량의 실제 주행·주차 감지가 아니다. 실제 화면은 CarUxRestrictions와 이용 맥락에 맞춰 후보를 표시하고, 정차 시설 선택·내비 등록은 별도 사용자 확인을 거친다.

## 누락·실패·데모

- 미래 수유·수면 기록은 해당 필요의 시각 계산에 쓰지 않는다. 다른 종류를 포함한 미래 기록도 전체 결과를 제한 상태로 표시한다. 잘못된 수면 순서도 수면 예보를 UNKNOWN으로 만든다.
- 사용할 수 없는 여정은 ETA 0으로 바꾸지 않는다. 경로가 없어도 기록 기반 예보는 유지하지만, 정보가 충분한 것처럼 `CONTINUE_JOURNEY`를 제안하지 않는다.
- 시각 덧셈이 Long 범위를 넘으면 `TIME_OUT_OF_RANGE`로 처리한다. 음수 시각으로 감싸지거나 예외로 앱을 종료하지 않는다.
- 보호자와 데모 출처가 섞인 기록은 서로 학습하지 않고 `MIXED_CARE_SOURCES`로 표시한다. 입력 중 데모 출처가 하나라도 있으면 결과의 `isDemo`를 유지한다.
- 결과에는 `care-forecast-v1`(알고리즘), `planning-policy-v1`(계산 정책), `public-context-2026-11-v1`(공개 참고 모델) 버전을 분리해 담는다.

## 공개 근거 (확인: 2026-11-11)

직접 쓴 요약이며 원문을 복제하지 않았다. 수유·깨어 있는 시간·카시트 시간은 개인의 건강 상태를 감지하거나 원인을 확진하는 근거로 쓰지 않는다.

- `cdc-breastfeeding-2026`: [CDC 모유수유 빈도](https://www.cdc.gov/infant-toddler-nutrition/breastfeeding/how-much-and-how-often.html). 초기 며칠에는 1~3시간, 이후 초기 몇 주·몇 달에는 일반적으로 2~4시간을 설명하지만 클러스터 수유와 긴 수면 등 변동도 명시한다. 6개월 이후에는 고형식과 아기의 신호에 따른 변화, 12~24개월에는 개인차를 설명한다.
- `cdc-formula-2026`: [CDC 분유수유 빈도](https://www.cdc.gov/infant-toddler-nutrition/formula-feeding/how-much-and-how-often.html). 초기 며칠에는 2~3시간, 이후 초기 몇 주·몇 달에는 일반적으로 3~4시간을 안내한다. 이후 고형식 전환과 하루 섭취 횟수 설명을 개인 간격으로 환산하지 않았다.
- `aap-car-seat-travel`: [AAP 여행 중 카시트 휴식](https://www.healthychildren.org/English/tips-tools/ask-the-pediatrician/Pages/Is-it-safe-for-my-baby-to-travel-in-a-car-seat-a-few-hours-at-a-time.aspx). 낮 2~3시간 간격의 여행 휴식 안내를 계획 맥락으로 사용한다. 차량 밖의 카시트를 일반적인 수면 장소로 취급하지 않는다.
- [The Lullaby Trust 카시트와 수면](https://www.lullabytrust.org.uk/safer-sleep-advice/product-information/car-seats-and-sids). 카시트는 주 수면 장소가 아니고 도착 후 평평하고 단단한 수면 장소로 옮기라는 안내를 수면 브릿지 해석의 경계로 삼았다. 해당 안전 안내를 분 단위 기상 예보로 바꾸지 않았다.
