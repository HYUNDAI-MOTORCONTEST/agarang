## 검증과 UI 상태

- 최신 GCP 검증: **공용 108개 + 서버 1개 = 109개 테스트 통과**, 실패·오류·스킵 0. 앱 debug·계측 APK 빌드와 설치, 실제 내비 읽기 검증 통과. 현재 빌드 입력 79개 파일이 검증 압축본과 일치함을 확인했다. [내비 검증 기록](navigation.md)
- 로컬에는 JDK·Android SDK가 없어 위 결과는 GCP 실행 결과다. 실행 스크립트 변경은 Bash 구문 검사와 실제 HOME/LAUNCHER 동작을 확인했다.
- 11/11~11/12 초기 캡처의 GCP AVD 화면 규격이 잘못돼 있었다. 공식 기기 프로필의 2560×1440·160dpi로 맞추고 Cold boot한 뒤 앱과 차량 시스템 UI를 다시 확인했다. 이전 규격의 시각 검증 주장은 정정했다. [화면 규격·재검증](care-records.md)
- 현재 앱은 기록·설정·연결 상태 위주의 기능 검증용 UI다. 최종 메인 화면, 정보 위계와 시각 디자인은 #7·#8에서 완성해야 한다.
- 실행 가능한 제출용 release APK와 전체 시연 동선은 아직 완성되지 않았다.

다음 구현 순서는 시설·정차 계획(#6), 출발 화면·디자인(#7), 울음 대응(#8), 핵심 시나리오 통합 검증·제출 준비(#12·#13)다. #5의 실제 경유지 등록 검증도 함께 해결해야 한다.
